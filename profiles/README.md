# Profils de mouvement locaux

Le profil KIT public est inclus dans l'application.

Les editions STL et Compatible utilisent des sequences de mouvement differentes.
Si tu disposes legitimement de ces sequences, copie `profile-template.json`, renseigne
les deux champs G-code du profil concerne, puis importe le fichier depuis l'interface.

Le fichier reste local et n'est jamais transmis a un serveur.
